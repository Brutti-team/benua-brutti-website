# Benua Brutti Website Assets

Upload the original Benua Brutti images into this folder.

Recommended filenames:
- hero-orange.jpg — homepage hero image
- founders.jpg — Lukman & Faznur / founders image
- bed.jpg — bed or bedroom furniture
- wood-display.jpg — wood decor / display piece
- console.jpg — console / living furniture
- coasters.jpg — small wood accessories
- showroom.jpg — shared showroom image
- map-preview.jpg — optional location/map preview

Once the images are uploaded here, the website code can be updated to use these local files instead of temporary image links.
